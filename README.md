# Setup

Development environment instructions for Wave Foundation projects, targeting
**Ubuntu 22.04.5 LTS or later on x86-64, using Bash**.

Start with the [development setup guide](setup/Setup.md). For Wave alone, follow
[section 1](setup/Setup.md#1-wave-development-environment), including the clone
and source-build steps. AOSP, Whale, and AriaJDK have separate sections.

Translations: [Deutsch](setup/Setup.de.md) · [Español](setup/Setup.es.md) ·
[Français](setup/Setup.fr.md) · [日本語](setup/Setup.ja.md) ·
[한국어](setup/Setup.ko.md) · [Русский](setup/Setup.ru.md) · [中文](setup/Setup.zh.md)

To install a prebuilt Wave release on Linux, macOS, or Windows, see the
[Wave installation guide](https://wave-lang.dev/docs/getting-started/install).
